# GSAPStackingCards

Scroll-pinned stacking cards built with GSAP ScrollTrigger + ScrollSmoother.

Open `index.html` in a browser — GSAP loads from a CDN, nothing to build.

- `index.html` — markup plus the GSAP/ScrollTrigger/ScrollSmoother script tags
- `style.css` — card layout, colors, placeholder sections
- `script.js` — pin + per-card slide-in, and a draggable debug panel for tuning
  `STACKING_CONFIG` live (drop `createDebugPanel()` for production)
